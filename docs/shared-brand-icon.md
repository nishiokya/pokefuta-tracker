# ブランドアイコン（ヘッダーと favicon）

## ヘッダー（30px）: `brand-mark.svg`

2026-10-11 採用: 「立てたふた＋白い見開きの本」。赤白の面と茶色の格子のマンホールを背面に、白い見開きの本を手前に重ねる。写真館はカメラ、図鑑は本で区別し、ふたの形と配色は両サイトで揃える。

- ふたの上半分は赤（`#DA3943`）、下半分は `#F6E6C4`。格子線と外枠は茶色（`#66363C`）。
- 30px表示用に輪郭線を太くし、viewBoxを内容に合わせて詰めている（48pxの線のまま30pxに縮めると0.8px程度になってにじむため）。PC/SPとも30pxで表示する。

## favicon・アプリアイコン: `brand-icon.svg`

2026-10-11 採用: **紺×山吹の上下2色のふただけ**（カメラ・本なし、両サイト共通）。検索結果では公式サイトの赤白のアイコンのすぐ近くに並ぶので、赤を使わず、紺で対比させる。

- 18pxの枠いっぱいの円。外周の縁 `#14273F`、上半分 `#24466E`、下半分 `#F2C14E`。
- 格子は中心から同じ距離に斜め2本ずつで、上下左右とも対称。上半分では山吹、下半分では紺で描く。
- 中央のボタン・横帯・両脇の突起は使わない。赤は使わない。
- faviconは16/32/48pxのICO、48/96pxのPNG、SVG。ホーム画面用は180px（マーク84%）。`inject_site_header.py` が全生成ページ・全言語の旧favicon指定を置き換え、Pagesビルドでルートのfaviconフォールバックへもコピーする。
- アプリアイコンは全面不透明な `#FFF5DE` のキャンバスへ合成する（iOS・maskableで透明部分が黒く出るため）。書き出し後に実寸と透明画素ゼロを確認する。
- favicon のURLは変えない（Google は URL を頻繁に変えないよう求めている）。
