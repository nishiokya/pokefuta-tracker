# トップ・タグ導線の計測

2026-09-19、PR #490の本番反映前にGA4プロパティ507799028へ以下のイベントスコープのカスタムディメンションを登録。

| パラメータ | 用途 |
| --- | --- |
| tag | トップのclick_hub_tagと地図のfeature_filter_clickに共通するテーマ識別子 |
| nav | クリックしたナビゲーション項目 |
| destination | 県slugなどの遷移先識別子 |
| result_count | 結果件数別の分類。0件等の空振りを区別するため指標ではなくディメンション |

tag_labelは表示用補助値で、言語をまたぐ集計はtagを使う。既存のfeature/feature_labelは今後送らず、地図のsurfaceはmap_tag_directoryとする。

click_pref_show_allは都道府県一覧の展開を数える。イベント件数とユーザー数は区別する。countは展開した全項目数であり、展開前の表示数ではない。

result_countの意味は各送信箇所に従う。地図のタグ一覧クリックではタグに属する件数を送り、他フィルタ適用後の画面表示件数とは限らない。イベント名を絞らず合算しない。

カスタムディメンション登録前のデータは遡って探索へ反映されない。pokemonや低優先の補助パラメータはこの対応では登録していない。
