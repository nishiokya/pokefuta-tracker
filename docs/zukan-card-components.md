# 図鑑の一覧カード

## なぜ一部だけ直っていたか

4ページは別の生成スクリプトでHTMLとCSSを持っていた。都道府県詳細と市区町村詳細は既に一部を共有しているが、一覧のカードは共有していなかった。

| ページ・対象 | 従来の違い | 今回共有する部分 |
| --- | --- | --- |
| `/pokemon/` 人気・地域応援・ランキング | 16:9の写真、独自の枠、地域応援だけ紫背景 | カード外枠、正方形の蓋写真、見出しサイズ・余白の変数 |
| `/prefectures/` 県カード | 独自の影と12px角丸、正方形の写真一覧 | 同じ外枠と写真HTML、見出しサイズ・余白の変数 |
| `/municipalities/` 上位自治体カード | 半透明背景、内側の影、丸い写真 | 同じ外枠と写真HTML、見出しサイズ・余白の変数 |
| `/summary/` 旅のテーマ・レアカード | 16:9の写真。CSS後半で枠・背景・影を再度消していた | 同じ外枠と正方形の蓋写真、見出しサイズ・余白の変数 |

summaryは同じセレクターを後半でも上書きしており、前半を修正しても打ち消される状態だった。この上書きを削除した。小さい蓋写真は既存の `manhole_tile_image.tile_image_url()` に合わせ、summaryも `_lid` → `_latest` の順に選ぶ。

## 今後の変更場所

`apps/scraper/zukan_cards.py` がカード外枠・蓋写真のHTMLとCSSの正本。各生成スクリプトはその部品を呼び出し、ページ固有の情報・リンク・レイアウトを組み立てる。県の写真ギャラリー、自治体のランキング表、summaryの横スクロールは各ページに残す。投稿写真そのもののカードやFAQなど、用途の異なる要素は対象外。

`test_zukan_cards.py` は4ページを実際に生成し、共有CSS・カード・正方形画像・リンク・画像なしの動作を検証する。カード外枠を個別CSSで再定義した場合も失敗する。Pagesの生成前に実行し、共通部品の変更もデプロイ起動の対象に含める。

## イベントと新設発表

`dataset/prefecture_events.json` の `kind: news` は県ページ用の新設発表。トップとsummaryのイベント欄からは除外する。県ページのSEO・案内には残す。謎解きとステッカーキャンペーンはイベントとして表示を継続する。分類と表示先の違いも同じ回帰テストで確認する。
